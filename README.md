# Mangal Foods

Mangal Foods is a premium Indian sweets, savouries, and gifting storefront.

## Deployment
This repository now supports **pure static deployment on GitHub Pages**.

- Static site source: `docs/`
- Deployment guide: `DEPLOY_GITHUB_PAGES.md`

## GitHub Pages Quick Setup
1. Push to GitHub.
2. Repository **Settings** -> **Pages**.
3. Source: **Deploy from a branch**.
4. Branch: `master`, Folder: `/docs`.
5. Save and wait for publish.

Live URL pattern:
`https://<your-github-username>.github.io/MangalFoods/`

## Notes
- No server/runtime is required for deployment.
- Product detail links use `product.html?slug=<slug>`.
